# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security flaw, secret scanner evasion, or path traversal vulnerability in `agent-project-onboarding`:

1. **Do not create a public issue.**
2. Send an email to `egecagintepe@gmail.com` or create a private GitHub Security Advisory.
3. Include reproduction steps.

We will acknowledge receipt within 48 hours.
